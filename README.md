# Personal webpage

Source for my personal webpage: https://castamartin.github.io/

It's a single HTML page plus the papers, slides and a photo. To change
something, edit `index.html` and commit — the site updates in about a minute.

Files:
- `index.html` — the page
- `photo_me.jpg` — photo
- `martin-casta-cv.pdf` — CV
- `papers/`, `slides/` — the PDFs the page links to
- `.nojekyll` — serve files as-is
- `download_files.py` — one-off helper that pulled the PDFs from Drive
